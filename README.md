Vision-Driven Dynamic Traffic Light System Using Edge AI

Project Overview

This project aims to improve traffic management by detecting vehicles and adjusting traffic signals based on traffic density.

Technologies Used

- Python
- OpenCV
- YOLO Object Detection
- Edge AI

Features

- Vehicle detection
- Traffic density monitoring
- Dynamic traffic signal control
- Traffic simulation

Project Files

- "Main.py" – Main project program
- "traffic_simulation.py" – Traffic simulation
- "yolo_traffic.py" – Vehicle detection
- "requirements_instructions.txt" – Setup instructions
- Traffic images and signal assets

How to Run

1. Install Python.
2. Install the required libraries.
3. Ensure the YOLO configuration and model files required by the code are available.
4. Run "Main.py".
