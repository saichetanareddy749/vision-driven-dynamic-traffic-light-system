Vision-Driven Dynamic Traffic Light System Using Edge AI

Project Overview

The Vision-Driven Dynamic Traffic Light System Using Edge AI aims to improve traffic management by detecting vehicles and adjusting traffic signals based on real-time traffic density. The system uses computer vision and YOLO-based object detection to support intelligent traffic signal control.

Technologies Used

- Python
- OpenCV
- YOLO Object Detection
- Edge AI

Features

- Real-time vehicle detection
- Traffic density monitoring
- Dynamic traffic signal control
- Traffic simulation
- Computer vision-based traffic analysis

Project Files

- "Main.py" – Main project program
- "traffic_simulation.py" – Traffic simulation module
- "yolo_traffic.py" – Vehicle detection module
- "requirements_instructions.txt" – Setup instructions
- Traffic images and signal assets – Resources used by the project

Installation and Setup

Prerequisites

- Python 3.x
- pip package manager
- Required Python libraries
- YOLO configuration, class-name, and model files required by the code

Steps to Install

1. Clone or download this repository.

2. Install Python 3.x if it is not already installed.

3. Open a terminal in the project folder.

4. Install the required dependencies:
   
   pip install -r requirements_instructions.txt

5. Ensure the required YOLO configuration and model files are available in the locations expected by the code.

How to Run

Run the following command from the project directory:

python Main.py

If your main file or dependency file has a different name, update the commands accordingly.
